Overview

The Binance Pay Payment Gateway Service allows you to accept crypto payments with zero gas fees directly into your Binance wallet, whether on your website, e-commerce store, or through a Telegram Bot.

1

Register Account

Sign up on the Merchant Portal to get your API keys.

2

Connect Binance

Enter your Binance Merchant API Key & Secret in Dashboard.

3

Connect Bot / Web

Integrate via Telegram Bot or REST Web API in minutes.

Authentication

All payment creation requests from external websites authenticate using your Gateway API Key header:

HTTP Header 
x-api-key: bg_live_your_merchant_api_key

1. Create Payment Order

POST /api/v1/payments/create Initiates a Binance Pay invoice

Generates a hosted payment URL, QR code, and mobile Binance App deep link.

Request Body (JSON):

{
  "orderAmount": "10.00",
  "currency": "USDT",
  "goodsName": "1-Month VIP Pass",
  "goodsDetail": "Access to private group",
  "merchantTradeNo": "ORDER_123456" // Optional, auto-generated if omitted
}

Code Example:

curl -X POST http://localhost:3000/api/v1/payments/create \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_MERCHANT_KEY" \
  -d '{
    "orderAmount": "10.00",
    "currency": "USDT",
    "goodsName": "1-Month VIP Pass"
  }'

3. Binance Webhook (IPN) & Verification

      
When a customer completes payment, Binance Pay sends an HTTP POST notification.


      

        

          Incoming Binance Webhook Structure
        

        
Headers:
  BinancePay-Timestamp: 1600000000000
  BinancePay-Nonce: 32_random_chars
  BinancePay-Signature: HMAC_SHA512_SIGNATURE
  BinancePay-Certificate-SN: YOUR_API_KEY

Body:
{
  "bizType": "PAY",
  "bizIdStr": "123456789",
  "bizStatus": "PAY_SUCCESS",
  "data": "{\"merchantTradeNo\":\"ORDER_123456\",\"totalFee\":\"10.00\",\"currency\":\"USDT\"}"
}
