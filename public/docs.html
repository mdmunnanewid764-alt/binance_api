Overview & Multi-Chain Support

The Binance Pay Gateway Service provides a high-performance REST API and Telegram Bot engine enabling you to accept cryptocurrency payments with zero hassle. Customers can pay via 4 seamless payment methods:

Binance Pay (0% Gas Fee)
BEP20 (BNB Smart Chain)
TRC20 (TRON Network)
ERC20 (Ethereum Network)

Authentication

All Merchant APIs require your Merchant Gateway API Key passed in the request header: 

x-api-key: bg_live_your_merchant_api_key_here

Or for User/Portal endpoints, pass the JWT Bearer Token: 

Authorization: Bearer YOUR_JWT_TOKEN

Create Payment Order

Creates a new crypto checkout order returning a hosted checkout URL, Binance Pay QR code, and BEP20/TRC20/ERC20 deposit addresses.

POST /api/v1/payments/create

Request Headers:

Content-Type: application/json
x-api-key: YOUR_MERCHANT_API_KEY

Request Body (JSON):

{
  "orderAmount": "25.00",
  "currency": "USDT",
  "goodsName": "1-Month VIP Subscription",
  "goodsDetail": "Access to private signal group",
  "merchantTradeNo": "ORDER_1787598000"
}

Response (201 Created):

{
  "success": true,
  "message": "Payment order created successfully",
  "order": {
    "merchantTradeNo": "ORDER_1787598000",
    "orderAmount": "25.00",
    "currency": "USDT",
    "status": "INITIAL",
    "checkoutUrl": "https://your-domain.onrender.com/checkout/ORDER_1787598000",
    "cryptoWallets": {
      "bep20": "0x386Ac338C488F61a9B4810fe17Fa2a78BE456108",
      "trc20": "TYasdf123456789TronUSDTAddress9988",
      "erc20": "0x386Ac338C488F61a9B4810fe17Fa2a78BE456108"
    }
  }
}

Query Payment Order

Retrieve the real-time status of any order by its merchantTradeNo.

GET /api/v1/payments/:merchantTradeNo

Response:

{
  "success": true,
  "order": {
    "merchantTradeNo": "ORDER_1787598000",
    "orderAmount": "25.00",
    "currency": "USDT",
    "status": "PAID",
    "paidNetwork": "BEP20",
    "transactionId": "0x987654321fedcba...",
    "paidAt": "2026-08-24T12:00:00.000Z"
  }
}

Submit On-Chain TxHash

Allows buyers or automated bots to submit the blockchain transaction hash for direct BEP20, TRC20, or ERC20 transfers.

POST /api/v1/payments/submit-tx 
{
  "merchantTradeNo": "ORDER_1787598000",
  "network": "BEP20",
  "txHash": "0x78ab9c...blockchain_hash_here"
}

Binance Pay Webhook (IPN)

Configure this webhook URL in your Binance Merchant Portal: https://your-domain.onrender.com/api/v1/payments/webhook

Telegram Bot Integration

  1. Get your Bot Token from @BotFather on Telegram.
  2. Login to Merchant Dashboard -> Click Telegram Bot.
  3. Paste your Bot Token and define product names & prices in USDT.
  4. Click Save & Launch Bot. Your bot will instantly go live supporting Binance Pay, BEP20, TRC20, and ERC20!
